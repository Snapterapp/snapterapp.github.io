접근성

보거나 듣거나 움직이는 방식이 달라도 Snapter를 편하게 즐기도록 돕는 기능과 켜는 곳이에요.

iPhone 설정을 따라요

  • 라이트 또는 다크: Snapter는 휴대폰의 화면 모드를 따라요. 직접 고르려면: 설정 → 테마.
  • 동작 줄이기: iPhone의 손쉬운 사용 설정에서 켜져 있으면 Snapter가 움직이는 효과를 줄여요. 앱에서: 설정 → 화면 및 접근성 → 움직임 줄이기.
  • 대비 증가: iPhone에서 켜져 있으면 Snapter가 글자를 더 또렷하게, 배경을 더 단순하게 바꿔요. 앱에서: 설정 → 화면 및 접근성 → 고대비.

앱에서 더 보기

  • 설정 → 화면 및 접근성 → 큰 글씨: 글자와 버튼이 조금 커져요. iPhone 전체에 설정한 글자 크기는 Snapter가 아직 따르지 않아요. 지금 작업 중이에요.
  • 설정 → 화면 및 접근성 → 색맹 친화 색상: 초록, 빨강, 주황을 구별하기 쉬운 색으로 바꾸고, 시간이 얼마 남지 않으면 타이머에 밑줄을 그어요.
  • 설정 → 소리 옵션 더 보기 → 소리 없이 진동만: 게임 소리가 꺼지고 대신 조금 더 세게 진동해요.
