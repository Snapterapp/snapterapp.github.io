利用規約

最終更新：2026年11月19日

フェアプレイ

Snapterは無料で遊べて、アカウントも不要です。写真はあなたのものです：送った写真は、そのラウンドの判定と、そのルームのプレイヤーへの表示に使わせてもらい、24時間以内に削除されます。AIジャッジが各ラウンドを判定しますが、間違えることもあります：どのプレイヤーも勝ちに異議を申し立てられ、あなたも「設定」から間違いを報告できます。本物を撮ること、思いやりを持つこと、画面や印刷物でジャッジをだまそうとしないこと。ルール違反の写真は受け付けず、違反をくり返すと24時間、7日間、または永久にプレイ禁止になります。

あなたのデータ

必要なのはニックネームだけで、メールアドレスはサインインを選んだ場合のみです。写真はラウンドの判定に使われ、各プレイヤーの最後の写真が結果発表でルームに表示されます。写真はすべて24時間以内に削除されます。匿名の集計（プレイ回数、平均判定時間）、デイリーチャレンジをプレイした場合の国、クルーやフレンド用のランダムなIDを保管します。広告なし、トラッキングなし、販売なし。

ゲームの記録

ゲームを安全に運営するため、プレイ統計（使ったニックネーム、ゲームとラウンド、写真の判定結果、チャレンジ、報告、警告）を保管します。見られるのはSnapterチームだけです。写真は24時間以内に削除されます。ただし、警告や利用停止の原因になった写真（終了後30日まで、または永久利用停止が続く限りモデレーター用）と、ジャッジについての報告に添えて送られた写真またはチャレンジで誤りと判明した写真（ジャッジ改善のため最大90日）は除きます。子どもに関わる写真は、誰によっても決して保管されません。

購入：Host PassとSnap Pass Premium

Host Passは任意の自動更新サブスクリプション（週額・月額・年額）で、どちらにしても、ルームのみんなは無料で遊べます。Host PassとSnap Pass Premiumは別々の商品です。Host Passはホスト向けの機能（追加モード、すべてのパックとオリジナルパック、より大きなルーム、タイマーとラウンドのオプション、そして専用の王冠、アバター、リアクション、光る名前）のためのもので、Snap Pass Premiumは含まれません。Snap Pass Premiumは1シーズン単位の買い切りの購入で、自動更新はありません。この変更の前にHost PassにSnap Pass Premiumが含まれていた場合は、現在のシーズンが終わる2026年12月2日までPremiumを使えます。お支払いは、購入を確定した時点で、またはプランに無料トライアルがある場合はトライアル終了時に、Apple IDに請求されます。現在の期間が終了する24時間前までに解約しない限り、同じ価格で自動的に更新されます。解約やプランの変更は、iPhoneの「設定」→ユーザ名→「サブスクリプション」からいつでもでき、解約しても、支払い済みの期間が終わるまではPassを使えます。Snap Pass Premium、コインパック、一部のコスメは買い切りの購入で、こちらもAppleを通じて行われます。支払いはすべてAppleが受け取り、返金もAppleが対応するため（返金の申請はreportaproblem.apple.comから）、私たちがあなたのカードを見ることはなく、返金されたパス、コインパック、コスメは回収されます。サーバーにはApp Storeの取引番号と購入の状態をあなたのアカウント（またはこのスマホ）とひも付けて保存しますが、これはあなたのデバイスでそれがあなたのものだと確認するためだけに使います。コードはフィンガープリントとしてのみ保存されます。

Snap Pass

Snap Passは、アカウントまたはこのスマホに次のものを保存します：シーズンのXPとその獲得元、クエスト、コインの増減、持っているコスメとそれぞれの入手方法、身につけているもの（ルームのプレイヤーに表示されます）、そしてデイリークエストがあなたの午前0時に切り替わるためのタイムゾーン。コインはプレイで獲得するか、コインパックで購入でき、現金としての価値はなく、換金も譲渡もできず、購入が返金された場合は回収されます。Snap Pass Premiumは1シーズン単位で別に購入する買い切りのもの（自動更新なし）で、それを含むコードでも手に入りますが、Host Passには含まれず、コインではどちらも買えません。「データを削除」ですべて消えます。

安全

すべての写真は、誰かの目に触れる前に、ヌード、暴力、ヘイトシンボル、薬物、身分証明書が写っていないかチェックされます。ほかのプレイヤーの写真にはすべて報告ボタンがあり、報告するとあなたの画面からすぐに消えて、より厳しい基準で自動的に再チェックされ、そのチェックで問題が見つかった写真や2人から報告された写真は、人が判断するまで全員から非表示になり、判断は24時間以内に行われます。ラウンドの結果発表からプレイヤーをブロックでき、その人と同じルームになることは二度とありません。自由に書けるチャットはなく、決まった挑発メッセージだけです。知らない人がいるルームでは標準アバターしか使えません。

子ども

Snapterのゲームは13歳以上のプレイヤー向けで、アプリはすべてのプレイヤーに生まれた月と年を尋ね、それより年下の人は見て回ることはできてもプレイや写真の送信はできません。子どもに有害なものは永久プレイ禁止となり、その場合も保存するのは写真のフィンガープリントだけで、写真そのものは決して保存しません。

あなたの年齢

Snapterで遊ぶには13歳以上である必要があります。アプリを初めて開くと、生まれた月と年を尋ねられるので、正直に答えてください。間違えた場合は、「設定 → 年齢を変更」で修正してください（7日に1回）。13歳未満のプレイヤーはアプリを開けますが、プレイ、ログイン、フレンドの追加、購入、写真の送信はできません。生年月日の使い方と保存方法については、プライバシーポリシーの「子どもと年齢」をご覧ください。
