サポート

お問い合わせ

ご質問、不具合、または間違いだと思う利用停止がありますか？snapterapp@gmail.com までメールでご連絡ください。アプリ内の設定 → 問題を報告からも送れます。

よくある質問

遊び方は？

新規ゲームをタップして、ルームコードを共有します。全員に同じアイテムが出され、その本物を最初に撮った写真がラウンドの勝ちです。写真はすべてAIの判定員がチェックします。ひとりなら今日のお題（Daily）かソロラッシュで遊べます。

友だちのゲームに参加するには？

ホームで友だちのルームコードを入力して参加をタップするか、送られてきた招待リンクを開いてください。

Host Passを復元・解約するには？

復元：設定 → Host Pass → 購入を復元。解約：iPhoneの設定 → ユーザー名 → サブスクリプション → Snapter。返金は reportaproblem.apple.com でAppleが対応します。

写真やプレイヤーを報告するには？

結果発表やスコアボードで写真の下の「報告」をタップします。送った人をブロックすることもできます。その他は設定 → 問題を報告、またはメールでご連絡ください。

なぜ年齢を聞かれるの？

Snapterのゲームは13歳以上のプレイヤー向けです。そのため、アプリは初回起動時にすべてのプレイヤーに生まれた年と月を尋ねます。入力を間違えた場合は設定 → 年齢を変更で直せます（初回はすぐに、その後は7日に1回）。13歳未満の方はアプリを見て回れますが、遊ぶことはできません。保管方法はプライバシーポリシーの「子どもと年齢」にあります。

データを削除するには？

写真は24時間以内に削除されます。それ以外をすべて削除するには、設定 → 利用規約・プライバシー・安全 → データを削除。またはメールをいただければ、こちらで削除します。
